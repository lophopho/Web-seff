# Web Surf для Google AI Edge Gallery

Навык `web-surf` для поиска в интернете и чтения конкретных ссылок. Рассчитан на короткий контекст локальной Gemma: до 2400 символов статьи за один вызов. Это чтение публичных страниц, а не управление браузером.

## Возможности

- Поиск через Bing; резервный вариант — DuckDuckGo. Выдача извлекается через Jina Reader.
- Автоматическая попытка прочитать первый результат поиска.
- Чтение указанного URL, возврат ссылок для дальнейшего перехода.
- Чтение длинных страниц порциями по `next_offset`.
- Короткие ответы по-русски со ссылками; явные ошибки и пометки неполных данных.

## Размещение на GitHub Pages

1. Создайте публичный репозиторий `Web-seff` и загрузите содержимое этого проекта в его корень, сохранив папки.
2. В Settings → Pages → Build and deployment выберите Deploy from a branch → main → / (root) → Save.
3. После успешного развёртывания откройте `https://lophopho.github.io/Web-seff/web-surf/SKILL.md`: должен появиться исходный Markdown.
4. В Edge Gallery → Agent Skills → настройки навыков → добавление по URL вставьте `https://lophopho.github.io/Web-seff/web-surf/` (без SKILL.md).
5. Включите `web-surf`, выберите Gemma и начните новый чат. Названия меню зависят от версии iOS-приложения.

Адрес обычного GitHub-репозитория и raw.githubusercontent.com не подходят для выполнения HTML: нужен GitHub Pages с корректным Content-Type. Файл `.nojekyll` должен остаться в корне.

## Ограничения и данные

Модель работает на телефоне, но запросы и URL отправляются Jina Reader; поисковые запросы достигают Bing или DuckDuckGo. Код не передаёт переписку целиком, не хранит историю и не пересылает cookies. Не используйте приватные ссылки, ссылки восстановления пароля или адреса с секретами. Проверяются публичные доменные HTTP(S)-адреса, но это не проверка DNS и не гарантия безопасности произвольного сайта.

API-ключ в этой версии не используется. Анонимные лимиты и доступность сервисов могут меняться. Поисковые CAPTCHA, блокировки, CORS/WebView-ограничения и изменения разметки могут помешать работе. При ошибке навык сообщает о ней; не подменяет поиск выдуманным ответом. Сниппет поиска не означает, что страница была прочитана. Возможны кэш, неполное извлечение и смещение текста между последовательными загрузками длинной статьи.

Навык не входит в аккаунты, не нажимает кнопки, не заполняет формы и не обходит ограничения доступа. Предусмотрено до 3 вызовов на запрос, а не бесконечный автономный обход сайтов. Этот предел задаётся инструкцией модели; время и объём каждого вызова ограничены кодом.

## Проверка

`node --test tests/web-surf.test.cjs`

Тесты выполняют настоящий HTML-скрипт в изолированной среде с подставленными сетевыми ответами: чтение URL, поиск, резервный поиск, пагинация, редиректы, ошибки, тайм-ауты и ограничения данных. Это не подтверждение доступности внешних сервисов или совместимости конкретной версии iPhone. Перед регулярным использованием выполните примеры выше на устройстве.
